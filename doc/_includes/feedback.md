## Feedback

We encourage you to help improve the quality of this guide!

If you spot a typo, a factual error, or a section that is incomplete or could be explained more clearly, please verify the behavior against the `master` branch and submit a pull request editing the Markdown files in the [`doc/` directory](https://github.com/Dynamoid/dynamoid/tree/master/doc). If you find something that needs fixing but cannot patch it yourself, please [open an issue on GitHub](https://github.com/Dynamoid/dynamoid/issues).
